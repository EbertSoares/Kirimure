# SVGs oficiais

Coloque nesta pasta os assets finais do Laboratório Digital Marinho.

Estrutura sugerida:

```text
background/
  recife-saudavel.svg
  recife-estressado.svg
  recife-degradado.svg
fish/
  especie-01-saudavel.svg
  especie-01-fraco.svg
  especie-01-morto.svg
  ...
debris/
  garrafa.svg
  sacola.svg
  mancha-oleo.svg
ui/
  ...
```

Os três fundos devem compartilhar exatamente o mesmo `viewBox`, proporção e enquadramento. Evite fontes externas, scripts, imagens remotas e elementos `foreignObject` dentro dos SVGs.
